Kleurmodellen 🎨

Op deze pagina leg ik uit hoe kleuren digitaal worden weergegeven met RGB en hexadecimale waarden.

RGB-model

RGB staat voor Rood, Groen en Blauw. Een computerscherm maakt kleuren door deze drie kleuren te combineren. Iedere waarde loopt van 0 tot en met 255.

Voorbeeldkleur

RGB: (50, 120, 255)

Hex: #3278FF

Zelf een RGB-kleur maken

Dit is ook een voorbeeld van invoer → verwerking → uitvoer.

RGB(50, 120, 255) → #3278FF

Decimaal en hexadecimaal

RGB gebruikt decimale getallen van 0 tot 255. Bij hexadecimale kleuren worden waarden geschreven met cijfers 0-9 en letters A-F.

Decimaal 255 128 0
Hex FF 80 00
GETALLENSTELSEL

Binair stelsel 🔢

Computers werken met bits. Een bit kan de waarde 0 of 1 hebben.

Wat is binair?

Het binaire stelsel is een getallenstelsel met slechts twee cijfers: 0 en 1. Iedere positie heeft een waarde die een macht van 2 is.

128 1
64 0
32 1
16 0
8 0
4 1
2 0
1 1

Bijvoorbeeld: 10100101 = 128 + 32 + 4 + 1 = 165.

Binary Bonanza

Via de afbeelding hieronder kun je Binary Bonanza openen. Het spel helpt om te oefenen met binaire getallen.

Video over het binaire stelsel

Waarom heb ik deze video gekozen?

Ik heb deze video gekozen omdat hij op een duidelijke manier uitlegt wat het binaire stelsel is en waarom computers met nullen en enen werken. De video laat ook zien hoe de verschillende machten van 2 worden gebruikt.

DIGITALE MEDIA

Compressie 🗜️

Compressie wordt gebruikt om bestanden kleiner te maken, bijvoorbeeld afbeeldingen, video's en andere bestanden.

🖼️

Bitmap

Een bitmapafbeelding bestaat uit veel kleine pixels. Foto's zijn meestal bitmapafbeeldingen.

Wanneer je een bitmap sterk vergroot, kunnen de pixels zichtbaar worden.

📐

Vector

Een vectorafbeelding wordt opgebouwd uit lijnen, vormen en wiskundige berekeningen.

Een vectorafbeelding kan meestal veel groter worden gemaakt zonder dat de randen pixelig worden.

Bitmap versus vector

Bitmap Pixels Goed voor foto's Kan pixelig worden
Vector Lijnen en vormen Goed voor logo's Goed schaalbaar

Video: Vector vs. Bitmap

Waarom heb ik deze video gekozen?

Ik heb deze video gekozen omdat het verschil tussen bitmap en vector direct wordt uitgelegd. Daardoor is goed te zien waarom een foto en een logo op een andere manier kunnen worden opgeslagen. Ik heb de video bekeken om de verschillen zelf beter te begrijpen.

KUNSTMATIGE INTELLIGENTIE

Artificial Intelligence 🤖

AI staat voor Artificial Intelligence, oftewel kunstmatige intelligentie.

💡

Waar gebruik ik AI voor?

Ik gebruik AI vooral als hulpmiddel bij het leren en programmeren. Ik kan bijvoorbeeld om uitleg vragen wanneer ik iets in mijn code niet begrijp of ideeën gebruiken om een probleem op te lossen.

Ik probeer de antwoorden niet zomaar over te nemen, maar te begrijpen wat de code doet. Daardoor leer ik van AI in plaats van alleen een antwoord te kopiëren.

📚

Leer ik iets van AI?

Ja. Door AI vragen te stellen kan ik bijvoorbeeld leren waarom HTML, CSS en JavaScript op een bepaalde manier worden gebruikt.

Ik moet de antwoorden wel controleren, want AI kan fouten maken. Daarom is AI voor mij vooral een hulpmiddel en niet een vervanging voor zelf nadenken.
